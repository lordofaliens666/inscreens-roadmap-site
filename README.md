# InScreens — роадмапы (публикация)

Статический сайт с двумя роадмапами стартапа, опубликованный через GitHub Pages.

**Содержимое зашифровано.** В `data/*.enc.js` лежит шифротекст AES-GCM; ключ выводится из пароля
через PBKDF2-HMAC-SHA256, 250 000 итераций. Расшифровка целиком происходит в браузере
(`assets/gate.js`) — пароль никуда не отправляется, а на сервере открытого текста нет.
Репозиторий публичный только потому, что GitHub Pages на бесплатном тарифе работает лишь
с публичными репозиториями; читаемого содержимого в нём нет.

Пароль в репозитории намеренно отсутствует. Его передают отдельно, тому, кому нужен доступ.

## Что где

| Путь | Что это |
|---|---|
| `index.html` | хаб: оба роадмапа с прогрессом |
| `business.html` | бизнес-настройка |
| `technical.html` | техническая часть |
| `data/*.enc.js` | зашифрованные данные |
| `assets/gate.js` | экран пароля и расшифровка |
| `assets/roadmap.js`, `assets/roadmap.css` | сам трекер |

## Как обновить содержимое

Прямо на сайте: ввести пароль → «Редактировать» → внести правки → «Экспорт». Скачается
`business.enc.js` или `technical.enc.js`, уже зашифрованный тем же паролем. Положить его в `data/`,
закоммитить — Pages пересоберутся сами.

Либо из приватного репозитория-источника `inscreens-roadmap`, где лежит открытый текст:

```bash
ROADMAP_PW='<пароль>' python3 build.py ../inscreens-roadmap-site
```

## Ограничения, о которых стоит знать

Пароль общий на всех — отозвать доступ у одного человека нельзя, можно только сменить пароль и
пересобрать файлы. Шифротекст остаётся в истории git: у того, кто однажды получил пароль, есть
доступ и к старым версиям. Для роадмапа это приемлемо, для секретов — нет, поэтому ключей,
токенов и паролей здесь быть не должно.

Прогресс и правки до экспорта хранятся в localStorage браузера и у каждого свои.
